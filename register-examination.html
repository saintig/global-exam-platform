3. Individual Question Upload

4. Bulk CSV Upload

Upload several questions using a CSV file.

Required CSV columns, in this exact order:
question_text, option_a, option_b, option_c, option_d, correct_option, explanation, marks, question_order

The first row must contain these column headings. Correct answers must be A, B, C or D. Save your CSV file using UTF-8 encoding where possible. Do not include an image_filename column.
