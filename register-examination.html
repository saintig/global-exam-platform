How to prepare your file

Word (.docx), Text (.txt) and PDF

One item per line, with a blank line between questions:

1. What is the capital of Nigeria?
A. Lagos
B. Abuja
C. Kano
D. Enugu
Answer: B
Explanation: Abuja is the capital. (optional)
Marks: 1 (optional)

2. Next question…
  • Start each question with a number such as 1. or 1).
  • Type the option letters A. B. C. D. yourself. Word's automatic lists are not read.
  • Every question needs an Answer: line with one letter, A to D.
  • PDF files need real text. Scanned or photographed pages cannot be read.

CSV and Excel

Put the column names in the first row. Columns are found by name, so their order does not matter. Extra columns are ignored.

question_text, option_a, option_b, option_c, option_d, correct_option, explanation, marks, question_order
  • Needed: question_text, the four options and correct_option. The rest are optional.
  • Leave marks empty to use the default marks.
  • Excel files are read from the first sheet. CSV files can use commas or semicolons.

File names

Any normal name works, such as Government SS1 Questions.csv, First Term Exam 2026.xlsx or My Questions (Final).CSV. Only the ending must be .pdf, .docx, .txt, .csv, .xlsx or .xls.

If something is wrong

Good questions are still accepted. Problem items are listed with their row or question number so you can fix them and read the file again.
